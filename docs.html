Mycelium-EI Language Introduction

Mycelium-EI (Enhanced Intelligence) is a domain-specific programming language designed for modeling and simulating quantum-enhanced biological networks.

Language Philosophy

Mycelium-EI combines the organic growth patterns of mycelial networks with the computational power of quantum mechanics. The language is designed to be:

  • Intuitive: Natural syntax that mirrors biological concepts
  • Powerful: First-class quantum computing support
  • Expressive: Rich abstractions for network modeling
  • Efficient: Optimized for large-scale simulations

Core Concepts

Networks

Everything in Mycelium-EI happens within a network. Networks define the scope and context for biological modeling:

network MyNetwork {
    // Network definition
}

Nodes

Nodes represent individual entities in the network - spores, growth points, or decision centers:

node origin = net.create("spore", [0.0, 0.0, 0.0]);
nodes branches = net.create_grid(5, 5);

Quantum Functions

Quantum-enhanced functions provide computational advantages for network operations:

quantum fn optimize_path(start: Node, end: Node) -> Path {
    // Quantum algorithm implementation
}

Simulation

Execute and visualize network dynamics:

simulate MyNetwork for 100.steps;
simulate MyNetwork for realtime;

Language Features

Feature Description Example
Type System Strong typing with biological abstractions Node, Connection, QuantumState
Quantum Integration Built-in quantum computing operations qc.hadamard(), qc.cnot()
Network Primitives High-level network operations net.create(), viz.render_3d()
Async Simulation Non-blocking network evolution simulate for realtime

Quantum Computing Integration

Mycelium-EI provides seamless integration with quantum computing concepts:

🔬 Quantum Features:
  • Quantum state management
  • Gate-level quantum operations
  • Quantum measurement and decoherence
  • Hybrid classical-quantum algorithms

Example: Bell State Creation

quantum fn create_bell_state() -> QuantumState {
    // Allocate 2 qubits
    let qubits = qc.allocate(2);
    
    // Create Bell state |00⟩ + |11⟩
    qc.hadamard(qubits[0]);
    qc.cnot(qubits[0], qubits[1]);
    
    return qc.get_state(qubits);
}

Tutorial: Basic Network Creation

Learn to create your first biological network using Mycelium-EI. This tutorial covers fundamental concepts and practical examples.

Learning Objectives

  • Understand network and node concepts
  • Create dynamic network structures
  • Implement basic growth algorithms
  • Visualize network evolution
1

Create Your First Network

Every Mycelium-EI program starts with defining a network. Networks are containers for nodes and their interactions:

network MyFirstNetwork {
    // Network contents go here
}
💡 Best Practice: Use descriptive network names that reflect their purpose, like "ForestGrowth" or "SupplyChain".
2

Add Network Nodes

Nodes represent entities in your network. Let's create some initial nodes:

network GrowthDemo {
    // Create origin node at coordinates [0, 0, 0]
    node origin = net.create("spore", [0.0, 0.0, 0.0]);
    
    // Create additional nodes
    node branch1 = net.create("growth_tip", [5.0, 0.0, 0.0]);
    node branch2 = net.create("growth_tip", [0.0, 5.0, 0.0]);
    
    // Create multiple nodes at once
    nodes grid_nodes = net.create_grid(3, 3, spacing: 2.0);
}
3

Implement Growth Logic

Add functions to control how your network grows and evolves:

network SmartGrowth {
    node origin = net.create("spore", [0.0, 0.0, 0.0]);
    
    // Simple growth function
    fn expand_network(center: Node, radius: Float) -> [Node] {
        let new_nodes = [];
        
        // Create nodes in a circle around center
        for angle in 0..360 step 60 {
            let x = center.x + radius * cos(angle);
            let y = center.y + radius * sin(angle);
            
            let new_node = net.create("branch", [x, y, 0.0]);
            new_nodes.push(new_node);
        }
        
        return new_nodes;
    }
    
    // Execute growth
    let first_ring = expand_network(origin, 3.0);
    let second_ring = expand_network(origin, 6.0);
    
    // Connect nodes
    origin.connect_to(first_ring);
    for node in first_ring {
        node.connect_to_nearest(second_ring, 2);
    }
}
4

Add Network Dynamics

Make your network respond to environmental conditions:

network AdaptiveNetwork {
    node origin = net.create("spore", [0.0, 0.0, 0.0]);
    
    // Environmental parameters
    let nutrients = env.create_gradient("nutrients", [10.0, 10.0], 5.0);
    let light = env.create_source("light", [0.0, 15.0]);
    
    // Adaptive growth function
    fn adaptive_growth(node: Node) -> [Connection] {
        let nutrient_level = nutrients.sample_at(node.position);
        let light_level = light.intensity_at(node.position);
        
        // Grow toward favorable conditions
        if nutrient_level > 0.7 {
            return create_radial_connections(node, 3);
        } else if light_level > 0.5 {
            return create_directed_connection(node, light.position);
        } else {
            return []; // No growth in poor conditions
        }
    }
    
    // Apply adaptive growth to origin
    let connections = adaptive_growth(origin);
    origin.connect_many(connections);
}
5
